AREESHA — BIRTHDAY WEBSITE
===========================

How to use:
1. Unzip the folder.
2. Open index.html in any modern browser.
3. Everything is already included except the Google Fonts connection; if offline, the browser will fall back to elegant system fonts.
4. The password for the final page is: EASTER

The website is intentionally designed as a multi-section, full-screen experience:
Loading → Intro → Compliments → Urdu Poetry → Messages → Wish → Gift → Password → Final Birthday Page.

Birthday date used: 7 October.
No “advance birthday” wording is used.
